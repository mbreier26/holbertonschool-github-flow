- To modify two files in Git, you edit their content locally, stage them together using the git add command, and commit the changes with a descriptive message to save them to your local history. Finally, you run git push to upload that commit to GitHub, making the updates available online.
- To resolve a conflict, you pull the changes to trigger the error locally, open the file to delete Git's markers, and manually fix the text. Afterwards, you stage the file using git add, commit the fix, and push it to GitHub to clear the warning.
